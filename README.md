# Análise de Visitação - Museu do Amanhã

## Objetivo
Analisar padrões de visitação e comportamento do público.

## Dados
Base com dados diários de visitação contendo:
- visitantes
- gratuidades
- meia-entrada
- inteira
- promocional

## Ferramentas
- Google BigQuery
- SQL
- Looker Studio

## Perguntas de negócio
- Quais dias têm mais visitantes?
- Qual o tipo de ingresso mais comum?
- Existe sazonalidade?

## Status do projeto
Em desenvolvimento
